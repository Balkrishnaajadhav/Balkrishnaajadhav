## 🧠 About Me

I'm **Balkrishna Jadhav**, a Data Scientist and Software Engineering Intern based in **Gujarat, India**, currently pursuing my **MCA at Parul University**. I believe consistency is the only bridge between surface-level theory and production-grade depth — which is why I'm **365 days into building in public**, shipping models and code every single day.

By day, I'm building predictive ML models at **Cerebra IT** and writing scalable backend code at **Zynthora.ai**. By night, I'm solving real-world data problems, cleaning raw datasets, and pushing my skills to the next level — one commit at a time. My goal is to land a full-time **Data Science or Analyst** role where discipline and hybrid DS/SWE expertise can create real impact.
